- `pnpm build` 通过 TypeScript 检查并生成生产静态文件；HeroUI 主题样式已验证。`pnpm test:i18n` 的 5 项国际化测试和 `pnpm test:security` 的 4 项补丁测试通过，冻结锁文件安装通过。
- 11 项安全回归覆盖登录限流与可信代理、密码重置/禁用竞态、慢速上传期间撤销分享及取消/清理上传、并发接收的容量预留、连接测试不占用全局锁、默认关闭接口文档和公开存储错误脱敏。
- 使用 ego-browser 检查登录、嵌套目录、面包屑、选择与删除、回收站恢复、配置保存、配置与错误状态提示、上传重名保留两份、取消任务。390px 手机宽度没有页面横向溢出。
- 响应式样式使用 ego-browser 在实际服务上检查：桌面文件、设置、传输、分享和用户页面显示正常；文件与设置页面在 320px、390px、768px、1024px 宽度下无横向溢出，长文件名正确省略。手机“更多操作”可打开菜单，并通过鼠标或键盘进入重命名弹窗，取消后不修改文件；桌面快捷按钮仍保留。
- 拖动移动使用 ego-browser 在隔离数据上验证文件拖入目录、目录连同内部项目移动、多选移动、拖回根目录及路径中的父目录。同名冲突显示“无法移动”弹窗，整组保留原位置和名称。外部文件拖入仍显示上传提示，390px 界面无横向溢出；浏览器验证未移动用户真实文件。
- 本地单后端静态部署与依赖检查通过；dedione 已完成 systemd + Caddy 原生部署及公网基础验收，当前版本 Docker 镜像尚未验收。

当前使用官方云端 Bot API，不需要应用凭据。已通过本机 HTTP 代理 127.0.0.1:7897 访问 Telegram Bot API，使用无效测试 Token 收到预期的 401。未使用部署者真实 Bot Token：频道权限、Telegram 实际上传/下载/删除，以及真实 5GB 文件的完整传输仍需添加存储配置后验收。模拟存储测试验证应用逻辑，不替代真实 Telegram 网络测试。
