# 帐号与权限

登录页使用蓝色云端存储主题背景，以渐变、云形轮廓、文件图标与连接线点缀，表单卡片在电脑和手机上居中展示。背景由本地 CSS 与 SVG 绘制，不加载外部图片或动画。

通过命令初始化唯一管理员，不提供公开注册或默认密码。管理员可创建普通帐号、禁用/启用普通帐号、重置密码；不能禁用管理员。用户可以验证旧密码后修改自己的密码。用户名使用字母、数字、下划线、点或连字符，最长 64 位，大小写不敏感且唯一；密码为 10～128 个字符。

每个帐号的目录、文件、任务与机器人配置独立。管理员通过网页只能管理帐号，不能浏览其他用户文件；能访问服务器或数据库的部署管理员仍具有服务器级权限。

登录使用随机服务端会话，数据库只保存会话令牌 SHA256；Cookie 为 HttpOnly、SameSite=Strict，默认有效 7 天，HTTPS 部署启用 Secure。写操作验证 CSRF 请求头和来源；前端开发通过 Vite 代理访问 `/api`，不开放跨域 CORS。

修改或重置密码撤销该用户全部会话，禁用也会撤销会话。登录在创建会话的同一写事务中重新核对密码哈希与帐号状态；密码修改和管理员写操作也在提交前复核帐号状态，旧请求不能在密码重置之后重新取得会话或覆盖新密码。禁用用户后不再调度其新转存块，已经开始的远程块可能完成，原文件保留。

登录按“大小写规范化后的帐号＋真实来源地址”限制 15 分钟内 10 次尝试，成功后清除此组合的记录；同一来源另有每分钟 60 次请求上限。来源只从明确配置的可信代理读取 `X-Forwarded-For`，其他连接忽略该头；部署方式见 [运行与部署](../deployment.md)。不同帐号不共用低阈值的失败计数。私人密码运算全站最多 4 个并发，同一帐号修改操作或同一登录组合最多 1 个，忙时直接返回 429，不建立无界等待队列。
