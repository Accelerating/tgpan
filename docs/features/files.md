# 文件系统与回收站

目录仅存在 PostgreSQL 中，Telegram 里保存的是文件块附件。系统不修改 Telegram 原始文件名来实现重命名；在网盘内重命名和移动只更新映射。

支持新建目录、面包屑导航、当前目录搜索（名称包含匹配）、按名称/大小/修改时间升降序排序，目录始终排在文件前。支持勾选批量移动、批量删除和单项重命名；移动不能形成目录环。名称规范化为 NFC，去除首尾空白，长度 1～255，禁止斜杠、控制字符、`.` 和 `..`。同目录中活动项目不能重名；上传冲突可取消或自动编号保留两份。

桌面端可以按住文件或目录名称，拖到列表中的目标目录行上移动；也可以拖到上方路径中的父目录或“全部文件”，移回上层或根目录。目标可接收时会高亮。拖动已勾选的项目会一起移动当前选中的所有项目；拖动未勾选的项目只移动该项目。回收站不支持拖动移动，手机端仍可通过勾选后的“移动”按钮选择目录。

移动只更新本地目录映射，不上传、下载或删除 Telegram 附件，已有分享继续有效。目标目录存在同名文件或目录时，拖动移动会弹窗提示，不覆盖、不自动重命名；多项移动作为一组提交，任何一项失败都不移动整组。不能把目录放入自身或子目录；拖回当前目录不执行移动。从电脑拖入文件仍表示上传，与网盘内拖动移动分开处理。

删除文件夹会把其中活动文件一起放入回收站。回收站展示删除操作的顶层项目，支持恢复、永久删除、清空。恢复优先回原目录，原目录在回收站时改放根目录；同名冲突时返回错误，项目保留在回收站，先调整同名项目再恢复。没有自动清空回收站。

未完成上传不能直接删除或随父目录移入回收站，应先在传输页面取消。取消的未完成文件无法恢复，需要永久删除后重新上传。永久删除后，原始消息通过持久化清理队列逐条尝试删除；失败记录在传输页面展示，支持重试，不因文件列表已删除而丢失清理记录。

批量移动在同一个数据库事务中执行，任一项目失败会回滚整组。其他批量操作逐项执行；某项失败时，之前已经成功的项目保留其结果，刷新列表后继续处理剩余项目。

官方云端 Bot API 的删除接口限制消息年龄不超过 48 小时。超期的原始附件可能无法由后台删除，清理记录会明确提示，用户可在 Telegram 频道内手动删除对应消息；删除后再次重试，已不存在的消息会视为清理完成。

已完成的图片、视频可点击名称或“预览”图标打开预览弹窗，下载按钮仍下载原文件。具体格式和播放限制见 [预览说明](preview.md)。

目录和已完成文件可通过行内“分享”按钮创建带标题、密码和有效期的分享链接，见 [文件与目录分享](shares.md)。目录分享支持访客逐层浏览、预览和逐文件下载。移入回收站会取消相关分享，恢复文件不会重新启用旧链接。

桌面文件列表保留行内快捷操作；手机布局将分享、预览、下载和重命名收进每行的“更多操作”菜单，回收站的恢复也从该菜单进入。手机端的文件大小显示在名称下方，不单独占用表格列；新建目录、上传文件与上传文件夹在标题下方自动换行排列。

“我的文件”在当前登录会话内保留浏览目录、搜索条件、排序和切页前的滚动位置；切换到传输任务、设置等页面后返回，不再自动回根目录。通过面包屑中的“全部文件”回到根目录。刷新浏览器后从根目录开始。传输任务和离线下载中的目录入口可直接定位目标目录，切换目录时清空搜索条件。
