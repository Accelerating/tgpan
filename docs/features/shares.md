# 文件与目录分享

## 创建和管理

文件列表中，目录和已完成上传的文件都有“分享”按钮。每次创建生成独立的随机链接 `/s/{token}`，可以为同一文件或目录创建多个不同密码或有效期的链接。

目录分享是实时视图，访问者可逐层打开子目录，通过面包屑返回分享范围内的上级目录，预览图片/视频并逐文件下载。目录必须在自身或后代目录内至少有一个已完成文件才能分享；空目录、只包含空子目录或未完成上传的目录不能分享。访客列表隐藏空子目录及未完成上传的文件，也不能通过直接指定空目录 ID 访问。分享根目录变空后，链接暂时无法访问，加入已完成文件后可再次访问。新加入和新上传完成的文件会在重新打开目录或刷新分享页后展示；移出分享目录或放入回收站的项目立即无法再通过该目录链接访问。分享根目录自身的重命名或移动不改变分享范围，也不影响链接。目录（包括空目录）不提供下载入口，当前只支持逐文件下载。

创建时支持：

- 分享标题：最多 200 个字符，去掉首尾空白；未填写或只有空格时，中文创建请求使用“好东西”，英文创建请求使用“Shared files”。已有标题和用户自定义标题保持保存值，不随访问者语言翻译。标题同时显示在访问页和浏览器标签页，密码验证前也能看到。
- 分享密码：可选，设置时为 4～128 个字符；不设置时，持有链接即可访问。
- 有效期：界面默认 7 天，可选 1 小时、1 天、7 天、30 天、自定义到期时间或永久有效；自定义时间必须在未来。后端按 UTC 时间戳校验，界面按访问者本地时区展示。

创建后可以复制链接；设置密码时可一并复制密码。密码仅在创建时保留于表单内存，服务端保存 Argon2id 哈希，后续不能从“我的分享”找回明文密码。

侧栏“我的分享”展示标题、文件名、到期时间、是否有密码和当前状态，支持复制有效链接和取消分享。已有分享不直接编辑密码、标题或有效期，需要取消后新建。取消分享不删除原文件。

链接使用当前浏览器访问网盘的域名生成。本地 `127.0.0.1` 链接只能在本机访问；要分享给其他人，需要用对方可访问的 VPS 域名打开网盘后创建或复制链接，并正确部署 HTTPS 和反向代理。

## 访问和媒体播放

分享页与登录页共用蓝色云端存储主题背景，使用本地 CSS 与 SVG 绘制渐变、云形轮廓、文件图标及连接线。内容展示在浅色卡片上，背景不拦截操作，也不加载外部图片或动画。

公开分享页的品牌显示为“Pan”，网页默认标题及描述不包含 TG Pan 或 Telegram 存储说明；加载分享信息后，浏览器标签页使用分享标题。

访问分享页不需要网盘帐号，不展示私人网盘导航，也不会调用私人帐号接口。受密码保护的链接先以页面水平、垂直居中的卡片显示标题与密码表单，适配电脑和手机，不泄露原文件名、大小或文件内容；验证成功后展示文件。

图片直接显示在网页，视频直接提供原生播放器，支持拖动进度条、播放暂停、音量和全屏。分享访问和私人预览复用同一个媒体组件及后端跨块 Range 流式输出，格式与编码限制见 [预览说明](preview.md)。不支持预览的类型仍能下载。

## 失效和权限

每次访问元数据、目录列表、下载、预览、HEAD 或新的 Range 请求都会检查链接、有效期、密码访问会话、原项目状态及所属帐号状态。目录访问还会沿当前父目录链检查项目属于分享根目录，禁止通过指定文件 ID 或目录 ID 访问分享范围外的项目；访客数据不包含私人祖先目录或存储凭据。正在输出内容的流至少每秒重新检查一次授权和目录归属；失效或移出目录时中断后续内容输出。已经下载或缓冲到访问者设备的数据无法撤回。

取消分享、到期、原文件移入回收站、所属帐号禁用都会阻止访问。移入回收站时会取消文件及目录内所有文件的分享，恢复文件后不会重新启用旧链接；永久删除文件时级联清除分享及访客会话。

密码验证通过后使用独立的 HttpOnly Cookie，路径仅限当前分享 API。会话最多 24 小时且不超过分享有效期，不能用于其他分享或私人网盘接口。密码不会放入链接、查询参数或媒体 URL；分享令牌以摘要检索，以加密形式保存供主人复制链接。密码尝试按分享和连接来源限制为 15 分钟内 10 次，限制只在失败时累计，验证成功会清除该来源记录。

来源地址复用可信代理校验；密码验证全站最多 2 个并发，同一分享与来源组合最多 1 个，忙时直接返回 429。公开下载和预览的初始存储故障使用中性提示，不暴露存储提供方或凭据配置诊断。

分享页与公共接口使用 no-referrer，并设置搜索引擎不索引；公共数据响应不缓存。密码解锁不要求私人帐号的 CSRF 令牌，但仍验证请求来源和 JSON 内容类型，私人写接口继续要求原会话校验。
