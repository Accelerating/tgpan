# PostgreSQL 表结构升级

版本 1 的初始化脚本为 `../schema.sql`，已发布的脚本保持不变。
后续变更在本目录新增 `002_description.sql`、`003_description.sql` 等 UTF-8 SQL 文件；版本必须连续且唯一。
新库从版本 1 开始执行全部脚本，已有库只执行高于当前版本的脚本。没有表结构变更时无需新增版本。

所有待执行脚本与版本号更新共用一个事务及 PostgreSQL 事务锁，失败全部回滚并阻止启动。
脚本不得包含 BEGIN、COMMIT、ROLLBACK 等事务控制语句，也不能使用 CREATE INDEX CONCURRENTLY 等不能在事务内执行的命令。
需要转换已有数据时，在脚本中明确编写数据更新 SQL；新增必填字段应先处理已有记录。
发布前使用旧版本数据测试升级，并备份数据库。应用不会自动降级；回退代码时应评估表结构兼容性，必要时从备份恢复。
